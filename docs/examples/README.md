# Reference examples

This directory holds example configurations and other reference artifacts that are useful for consultation but are not active project configuration.

| Example | Purpose |
| --- | --- |
| [`aws-device-farm-appium-python.yml`](aws-device-farm-appium-python.yml) | Stock AWS Device Farm Appium Python/pytest test spec retained as a reference |

The active Robot Framework Device Farm configurations are [`../../testspec.yml`](../../testspec.yml) for iOS and [`../../testspec-android.yml`](../../testspec-android.yml) for Android. Do not upload the example spec without adapting its pytest commands and settings to the intended test package.

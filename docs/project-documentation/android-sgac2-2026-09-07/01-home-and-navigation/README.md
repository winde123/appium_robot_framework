# Home, navigation, settings and help

Last reviewed: 2026-09-07

A visual guide to the installed MyICA staging app's home screen, service hubs, navigation drawer, settings and support destinations, including loaded privacy/terms pages and the home scam-advisory link.

[Word walkthrough](01-home-and-navigation.docx)

| Flow | Observed outcome |
| --- | --- |
| Home and service hubs | Home, favourite shortcuts, Citizen and Resident hub, and Foreign Visitor hub opened. |
| Home external links | Scam-advisory banner opened ScamShield. The translation-feedback link opened ICA Contact Us. |
| About | About MyICA, About Us and ICA website opened. The app identifies itself as 2.0.0(13) (STAGING). |
| Privacy and terms | Both external pages fully loaded. Privacy overview text, the Terms section list and expanded General text captured. |
| Help | Contact Us, Feedback, FAQ on AskGov, GovTech Report Vulnerability, and native Troubleshooting captured. No message or report sent. |
| Settings | Language, tutorial and favourite-shortcut settings opened. English retained; no exhaustive language rerun. |
